The problem

Tasks get lost between
chats, notes and spreadsheets

Most small teams don't lack effort — they lack one shared place that shows what's happening. These are the everyday frictions Taskboard was built around.

💬 "who's on the copy?" 📝 todo.txt 📊 tasks_v3_final.xlsx 📌 sticky note

Work is scattered

Tasks live in messages, documents and personal lists, so nobody sees the whole picture.

Ownership is unclear

When a task has no visible owner, it's easy for everyone to assume someone else has it.

Deadlines slip silently

Due dates buried in text don't stand out, so overdue work is noticed late.

Big tools feel heavy

Full project suites need accounts, setup and a connection before you can track a single task.

03 · Change status

Move work forward, your way

There are four ways to change a task's status, so updating the board never slows you down.

  • Drag & drop a card to another column — or to a new position in the same one
  • Click the circle to mark Done (click again to send back to To Do)
  • ⋯ → Move to from the card menu
  • Status selector inside the edit form

Find any task instantly

The search box filters the board as you type, matching the task name, assignee and description. “My tasks only” narrows the board to your own work.

05 · Themes

Seven themes, including Focus mode

Pick a look from the 🎨 Theme menu. Seasonal themes add colors, a greeting badge and gentle falling decorations. Your choice is remembered with your tasks.

  • Focus mode hides the sidebar, descriptions and tags, and dims every column except In Progress
  • Decorations turn off automatically when the system asks for reduced motion

Limitations & required resources

Where Taskboard is today

Taskboard is currently a single-user prototype. Here's what it doesn't do yet, and what running it for a real team would take.

Not yet implemented

Visible in the interface or expected in a team tool, but not working today.

Data stays in one browser

Tasks live in that browser's local storage. There's no sync between devices or people, and clearing site data (or a private window) loses them.

No accounts or real sharing

There's no sign-in. “Me” is fixed to Kevin, the teammate list is built in, and the Share and Invite buttons don't do anything yet.

One project, Board view only

Other sidebar projects, Home, My tasks, Inbox, Reporting, Portfolios and Goals, plus the Overview, List, Timeline and Calendar tabs, are placeholders. The “On track” status is fixed.

No notifications or collaboration

There are no reminders, comments, attachments, subtasks or task dependencies.

Touch drag not verified

Drag & drop uses the browser's mouse drag events and may not work on phones or tablets. The ⋯ menu and edit form still change status there.

Needed for real operation

Resources a team deployment would require.

Backend & database

A server API and database so tasks are stored centrally and backed up.

Authentication & permissions

User accounts, team membership and access rules for who can see or edit each project.

Real-time sync

Live updates (for example over WebSockets) so changes appear for every teammate at once.

Hosting & notifications

A hosted web address with HTTPS, plus an email or push service for due-date reminders.

Security, privacy & QA

Security review, a privacy policy, mobile and touch testing, and an accessibility check.
